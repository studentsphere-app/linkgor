Authenticates a student session using school instance ID, CAS credentials, and returns user details along with the session token.

## Usage

```typescript
import { loginWithCredentials } from 'linkgor';

const user = await loginWithCredentials('epsi', 'john.doe', 'password');
console.log(user.token);
```

## Parameters

<TypeTable
  type={{
    instanceId: {
      type: 'string',
      description: "The unique identifier of the school instance (e.g., 'epsi', 'idrac', '3a').",
    },
    username: {
      type: 'string',
      description: "The student's username (usually 'firstname.lastname').",
    },
    password: {
      type: 'string',
      description: "The student's portal password.",
    },
  }}
/>

## Return Value

Returns a `Promise` resolving to a [User](/docs/types/user) object.
