---
title: CD_INSTANCES
description: Predefined list of school instances in the Compétences & Développement group.
---

```typescript
CD_INSTANCES: Instance[] = ...
```

An array containing only the school instances belonging to the **Compétences & Développement (C&D)** group (such as EPSI, IDRAC, IFAG, 3A, WIS, etc.).

## Usage

```typescript
import { CD_INSTANCES } from 'linkgor';

console.log(CD_INSTANCES);
```
