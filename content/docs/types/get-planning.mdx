Fetches the timetable lessons from the schedule server using the session token.

## Usage

```typescript
import { getPlanning } from 'linkgor';

const lessons = await getPlanning('epsi', token, {
  start: new Date('2026-09-01'),
  end: new Date('2026-09-30')
});
```

## Parameters

## Return Value

Returns a `Promise` resolving to an array of [Lesson](/docs/types/lesson) objects.
