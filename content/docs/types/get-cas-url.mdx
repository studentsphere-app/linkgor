Retrieves the official Central Authentication Service (CAS) base server URL for a given school instance ID.

<Callout title="Why does this exist?" type="info">
  While all compatible schools currently route to the same Central Authentication Service (CAS) base URL, this function is maintained to ensure public API consistency. It also future-proofs the library in case the IGENSIA and C&D groups decide to partition or split their CAS servers in the future, as they have done historically for their respective apps.
</Callout>

## Usage

```typescript
import { getCASURL } from 'linkgor';

const casUrl = getCASURL('epsi');
// => "https://cas-p.wigorservices.net/cas/login"
```
