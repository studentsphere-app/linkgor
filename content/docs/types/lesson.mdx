The `Lesson` object represents a single class session parsed from the school timetable schedule server.

```typescript
interface Lesson {
  ColorBlue: number;
  ColorGreen: number;
  ColorRed: number;
  Commentaire: string | null;
  CoursMixteInfoBulle: string | null;
  CoursMixtePicto: string | null;
  Description: string | null;
  Duree: number | null;
  End: string;
  EndTimezone: string | null;
  FondCour: string | null;
  IsAllDay: boolean;
  LibelleGroupe: string | null;
  LibelleSemaine: string | null;
  LienTrack: string | null;
  LogoEcole: string | null;
  Matiere: string | null;
  NoCours: number;
  NoGroupe: number;
  NomEcole: string | null;
  NomProf: string | null;
  Origine: number;
  RecurrenceException: string | null;
  RecurrenceID: string | null;
  RecurrenceRule: string | null;
  Salles: string | null;
  Start: string;
  StartTimezone: string | null;
  TeamsUrl: string | null;
  TeamsURL: string | null;
  Title: string | null;
}
```
