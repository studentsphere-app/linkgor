---
title: IGENSIA_INSTANCES
description: Predefined list of school instances in the IGENSIA Education group.
---

```typescript
IGENSIA_INSTANCES: Instance[] = ...
```

An array containing only the school instances belonging to the **IGENSIA Education** group (such as IGENSIA RH, IPI, ICD, etc.).

## Usage

```typescript
import { IGENSIA_INSTANCES } from 'linkgor';

console.log(IGENSIA_INSTANCES);
```
